# Message Sender 📩

A simple and responsive web application built with **HTML, CSS, and JavaScript** for creating and delivering messages through an easy-to-use interface.

## 🚀 Features

* 📩 Send and manage messages
* 💻 Clean and simple user interface
* 📱 Responsive design
* ⚡ Lightweight and fast
* 🎨 Built with pure HTML, CSS, and JavaScript
* 🔄 Interactive user experience

## 🛠️ Technologies Used

* **HTML5** – Structure
* **CSS3** – Styling and responsive design
* **JavaScript** – Functionality and interactivity

## 📂 Project Structure

```text
Message-Sender/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## ▶️ How to Run

Clone the repository:

```bash
git clone https://github.com/VaibhavSain/Message-Sender.git
```

Open the project folder and launch `index.html` in your browser.

No additional dependencies or installation are required.
